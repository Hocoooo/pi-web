# 输入时补全：最小交互原型（非生产功能）

## 问题与范围

验证已选定的交互：桌面端、光标末尾、单条灰字后缀、停顿触发、Tab 采纳、Esc 取消、补全模型独立选择、默认关闭。不进行多套视觉方案比较。

后续已按用户要求实现正式接入，见 [输入时草稿补全](draft-completion.md)。本文件只描述此前的模拟原型，不代表真实请求的实现或验收。

原型交付是**独立单文件 HTML**，不是已经接入 Pi Web 的 AI 补全功能。使用固定示例响应和模拟延迟，不调用模型、不上传草稿、不修改正式 `ChatInput`、不发送 Agent 请求。模型选择仅切换模拟延迟，发送仅添加本页内存记录。

## 入口与运行

双击 [draft-completion.prototype.html](../../components/prototypes/draft-completion.prototype.html)，使用桌面浏览器打开。无需服务器、安装、构建或凭证。刷新即重置所有状态，不使用浏览器存储。

文件与输入框组件相邻，明确命名为 prototype；不放入 `public/`，不提供生产路由。待体验确认后记录结论，正式实现时重新设计与测试；原型应归档到临时分支，不作为生产组件保留。用户已要求按该范围正式接入；当前保留此文件作为先前交互参考，未把原型导入正式组件，也未自动切换或提交分支。

## 行为契约

- 开关默认关闭。模型选项为模拟快速（250ms）/慢速（1800ms），加上固定 600ms 停顿时间。
- 开启、聚焦、至少 4 个非首尾空白字符、光标末尾且无选区、无 IME/其他菜单/主会话运行阻塞时，才调度请求。
- 灰字使用与 textarea 同字体、同宽度、同步滚动的镜像层；灰字不是实际草稿。
- 无修饰键 Tab 只采纳灰字；Enter 只模拟发送实际草稿，Shift+Enter 换行。无建议时 Tab 保留原生焦点行为。
- Esc 丢弃当前建议或请求，当前草稿不立即重试；继续输入后恢复。采纳后也不立即重复请求。
- 草稿、光标、焦点、模型、会话或阻塞条件变化使请求失效。模拟请求刻意不取消，通过 request id / revision / session 与当前可补全条件拒绝旧结果。
- 原生 composition 事件和独立模拟 IME 开关均阻塞补全；compositionend 后短窗口避免确认候选用的 Enter 误发送。
- 页面展示草稿、灰字、光标、请求、版本、模型、阻塞原因、丢弃次数、模拟发送次数；提供自由操作和正常采纳/过期响应/输入法取消三组顺序引导。

## 手动体验

1. 打开文件，默认关闭；点击“填入示例”，等待约 850ms。期望出现“的参数校验和错误处理”。
2. Tab 采纳，模拟发送次数仍为 0。Enter 后才增加到 1。
3. 再填示例，灰字出现后直接 Enter。发送记录应只有原草稿，不包括灰字。
4. 选择“旧结果晚到”，依次执行步骤。期望旧结果丢弃、草稿为空。
5. 选择“输入法与取消”，依次执行步骤。期望组词期间无请求，结束后出灰字，取消后不立即复现。
6. 自由尝试慢模型期间继续输入、切换模型、关闭开关或切会话。期望不会写入旧建议。
7. 选中文字、移动光标到中间、切换窗口焦点、打开模拟菜单/运行阻塞。期望不展示可采纳灰字；恢复有效条件后才重新请求。
8. 手动输入多行示例 `请帮我` + 换行 + `检查这个接口`，并缩小窗口观察换行和滚动对齐。

## 验证边界与关联功能

原型不新增正式测试套件。本轮已通过内联脚本语法检查、`git diff --check` 和一次性 Playwright/Chromium 冒烟检查：Tab 采纳后发送次数仍为 0、Enter 不包含未采纳灰字、过期响应丢弃、模拟 IME 阻塞、Esc 后不重新弹出、光标中移清除、慢响应期间改稿只展示最新建议、关闭后清除。浏览器未报告脚本错误；检查了多行截图与镜像层宽度/字体/行高/padding 一致。真实中文 IME、各平台字体/缩放/滚动对齐仍需人工体验。固定响应不证明真实 AI 质量、网络取消、费用和延迟。

菜单开关只模拟阻塞，不实现现有菜单；没有接入 session/leaf、历史上下文、可用模型列表、Next Cue 或设置持久化，也没有移动端采纳按钮。

后续集成必须遵守 [下一轮提示词建议](next-prompt-suggestions.md) 的独立推理与 Tab 不发送边界，以及 [焦点导航](chat-focus-navigation.md) 的键盘优先级。草稿上传应单独授权，不能继承 Next Cue 开关。正式实现时同步本契约与 [索引](README.md)，补充真实模型服务和 UI 测试，不能将原型冒烟检查当成生产验收。
