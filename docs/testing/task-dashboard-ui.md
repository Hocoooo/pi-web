# 任务看板 UI 检查记录

## 范围与结论

2026-10-10：检查新版悬浮任务看板的主要界面及二级流程；筛选改为“搜索 / 项目 / 排序 + 更多条件 + 可移除的已选条件”。修复检查中发现的问题后，以下验证通过：

- `e2e/task-dashboard-ui.mjs`：**104 个场景检查**。桌面浅色、390px 触摸深色各 27 个流程；另有 50 个尺寸/语言/空态渲染检查。
- `e2e/task-dashboard-panel.mjs`：浮层开关、聊天/任务草稿、目录选择器叠层、聊天导航、准备材料、普通 New、IME/Escape/焦点、旧 URL 等回归通过。
- 任务资料、顺序、视图、共享重点、列、归档、AppShell 草稿导航与 stacked-dialog 定向测试：**97 项通过**。
- TypeScript、改动文件 ESLint、`git diff --check` 通过。

这不是“所有输入、浏览器和真实后端条件均无问题”的保证。下表区分已测 UI 与未验证边界。

## 测试方式

复用已存在的健康开发服务器，不启动第二个 dev、不运行生产 build。浏览器拦截全部 `/api/**`：

- 创建、编辑、移动、归档、列配置/删除、保存视图、人工共享重点使用 Git 树外临时真实 task store。
- 对话元数据/关联/改绑、AI 整理、任务准备使用合成响应；AI 整理的错误、延迟、取消和生成结果都是 fixture，不调用 provider。
- 合成生成草稿的发布不验证真实 provenance 签发链；该链仍属于已有服务端整合测试，不以本 UI 套件替代。
- 测试断言没有 Agent 写请求，且只有显式点击才请求合成生成。
- 每个场景检查表单、fieldset、详情及区域的横向边界；看板本身、代码块和表格允许独立横滚。记录浏览器异常并要求为空，保存逐场景截图及 `report.json`。
- 对主要截图进行了人工视觉复核，不只是检查 DOM 存在。没有固定像素基线；排版断言不等同完整 WCAG 审计。

### 尺寸、主题与语言

- 深流程：1440×960 英文浅色；390×844 英文深色，启用触摸。
- 渲染矩阵：320×740 简体中文深色；360×780 繁体中文浅色；768×1024 英文浅色；844×390 简体中文深色横屏；1280×800 繁体中文深色。
- 各矩阵覆盖看板、简化筛选、更多条件、新建、列设置、详情、共享重点编辑/预览、整理无模型空态。
- 额外 390×844 空看板覆盖筛选无标签、新建、列设置。

## 本轮修复

1. 筛选表单默认不再铺开状态、优先级和全部标签；已选条件可见可移除，保存视图放在次级区域。
2. 详情提取为 `TaskInspector`，位于筛选/拖拽投影之外；只缓存查看过的详情，关闭隐藏而非丢弃局部状态。移动、归档、筛选不会卸载当前详情，生成草稿即使不在可见卡片中仍能直接审核。
3. 当前对话整理入口复用草稿保护，不能覆盖既有人工共享重点草稿。
4. 移动/归档错误及精确重试显示在详情中；整理失败显示在操作附近并滚入视野。
5. 关闭二级流程后恢复浮层内焦点，父面板观察子组件局部 DOM 变化并约束焦点，同时允许更上层 portal 对话框。隐藏期间不为详情记录背景聊天作为焦点返回目标。Summary/Relation 同时保护 `isComposing` 和 Safari `keyCode=229`。
6. 长代码预览修复 CSS grid 的隐式最小宽度；长标题、路径、改绑名称可换行。只有看板列独立横滚，不再拖走上方筛选/表单。
7. 复选框不再继承文本框 padding；列删除同意项保持横向排列。选择框补显式名称。
8. 活动失败时对话列表显示未知，不再把上次结果呈现为当前活动。
9. 全部任务列表的归档卡片有标记；列表选择器显示归档数。
10. 详情关闭栏滚动时保持可见；无模型/无可用来源时给出下一步说明；当前对话菜单选择操作后收起。

## 重跑入口

```sh
# 先确认并复用健康 dev。套件自身不启动服务。
E2E_BASE_URL=http://127.0.0.1:30142 node e2e/task-dashboard-ui.mjs
E2E_BASE_URL=http://127.0.0.1:30142 node e2e/task-dashboard-panel.mjs
node_modules/.bin/tsc --noEmit
```

脚本输出新建的 `/tmp/task-ui-*/report.json` 和截图目录；每次均使用新临时数据。不要把测试浏览器截图中的合成任务当成用户真实数据。
