# 05: 筛选、自动排序与保存视图

**What to build:** 用户可以组合任务筛选、切换手动或自动排序，并保存常用筛选条件；在筛选结果中仍能安全改变任务状态，不会丢失隐藏任务。

**Blocked by:** 02（编辑任务资料与完善卡片）、03（拖拽移动与手动排序）、04（把已有对话归入任务）。

**Status:** resolved

## Acceptance criteria

- [x] 支持文字、项目、状态、优先级、标签和是否有 AI 正在工作的筛选，可组合使用；包含无项目任务的明确选择及无结果反馈。
- [x] 默认总览可看所有项目，切到单项目不改变任务本身的归属；筛选只影响视图，不写回任务状态。
- [x] 用户可保存命名的筛选条件并再次打开，刷新及服务重启后仍可用；损坏或失效条件有可理解反馈，不能默默返回越界数据。
- [x] 支持手动排序以及优先级、最近更新等自动排序，使用已存在的任务属性和确定性同值规则；切换不改写保存的手动顺序。
- [x] 自动排序时禁用列内拖拽调序并说明原因，仍可跨列移动任务；移动后按所选排序重新呈现，不伪装能固定任意位置。
- [x] 筛选状态下移动、拖入可见空列或移出筛选范围，仅改变指定任务；隐藏任务不丢失、不重复、不被重排或批量覆盖。
- [x] AI 工作提示变化后相关筛选正确更新，断线或重开页面后重新同步；筛选本身不启动 Agent 或模型请求。
- [x] 网络失败与两个页面保存条件或移动任务竞争有正确反馈，重试不生成重复记录，页面不能把未保存状态宣称为成功。
- [x] 公共操作与浏览器测试覆盖组合条件、无项目、空结果、保存再打开、筛选下移动、排序切换、失效条件与失败恢复；键盘和触摸可完成同等核心流程。
- [x] 测试使用临时资料与模拟运行态，同步看板合同与测试入口，报告未验证浏览器和数据量限制。

## Scope and handoff

02 提供可筛选属性，03 提供手动顺序与安全移动，04 提供对话运行提示，因此三项都是真实前置依赖。每个筛选不能各自扫描完整会话记录。

不新增统计图表、任意布局、自定义查询语言或多人共享视图。可自定义列由 13 提供；本票据按稳定列身份保存条件，后续列删除的失效处理由 14 接续。
